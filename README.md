# 🚀 Personal Portfolio — Edwin Kipleting

A modern, responsive, and animation‑rich developer portfolio built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.  
This portfolio showcases my work, skills, design philosophy, and contact information — crafted with a strong focus on UI/UX, motion, and clean architecture.

---

## ✨ Features

- ⚡ **Fast & lightweight** (Vite + React)
- 🎨 **Modern UI/UX** with Tailwind CSS
- 🎞️ **Smooth animations** powered by Framer Motion
- 📱 **Fully responsive** across all devices
- 🧩 **Modular components** for easy scalability
- 🖼️ **Project cards with hover overlays**
- 📬 **EmailJS contact form** with validation + toast notifications
- 🎯 **Dark theme** with consistent brand colors

---
